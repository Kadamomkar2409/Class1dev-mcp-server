1. The Shift-Left AI FinOps Opportunity: Why MCP Matters for Class1

Strategic Value Thesis for Founder Review

Labelled Product Hypothesis: Class1 today operates primarily at Pull Request (PR) review time via CLI and GitHub Actions. Exposing Class1 through the open Model Context Protocol (MCP) creates an entirely new category: In-Editor Shift-Left AI FinOps.

The PR-Time Barrier (Today's Friction)

When an engineer swaps models (e.g. gpt-4o-mini → gpt-4o) or increases token caps, cost spikes are discovered only after code is authored, tested, and pushed to GitHub. Reworking prompt architectures or seeking budget exceptions at PR review creates development friction and release delays.

The MCP Shift-Left Advantage (Phase 1 Proof)

With MCP, coding assistants (Claude Desktop, Cursor) query Class1's takeoff engine while the code is being written. Developers receive immediate tail-risk percentiles and budget verdicts before commit, and every evaluation persists to an immutable governance ledger in Neon PostgreSQL.

4. Connecting Claude & Cursor via Streamable HTTP Transport Mode

Phase 1 is verified over Streamable HTTP on port 3000. Start the server with npm start (or node dist/index.js). Every request strictly requires Authorization: Bearer <AUTH_SECRET>, protected by sliding-window rate limiting (60 req/min) and 1 MB payload limits.

Cursor IDE • Native HTTP / SSE Transport

Configure in .cursor/mcp.json or Cursor Settings → Features → MCP: 

{
  "mcpServers": {
    "class1-finops-http": {
      "url": "http://127.0.0.1:3000/mcp",
      "headers": {
        "Authorization": "Bearer <YOUR_AUTH_SECRET>"
      }
    }
  }
}

• Status: Native HTTP Streamable transport supported directly in Cursor.

Claude • HTTP Transport via SSE Bridge

In %APPDATA%\Claude\claude_desktop_config.json (or Claude Code CLI): 

{
  "mcpServers": {
    "class1-finops-http": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "http://127.0.0.1:3000/mcp",
        "--header", "Authorization: Bearer <YOUR_AUTH_SECRET>"
      ]
    }
  }
}

• Claude Code CLI: claude mcp add class1-finops --url http://127.0.0.1:3000/mcp --header "Authorization: Bearer <TOKEN>"
